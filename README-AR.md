# فريق أوسكار البرمجي — v3.8.0

هذه النسخة بدون مجلدات، وجميع الملفات في نفس المستوى.

أهم الإصلاحات:
- حذف نظام المزامنة القديم بالكامل.
- Turso أصبح المصدر المباشر لبيانات التطبيقات والتصنيفات والعروض والإعدادات.
- حفظ أي تعديل من admin.html مباشرة في Turso ثم تحديث النسخة المحلية.
- المتجر يقرأ أحدث البيانات من Turso ويستخدم النسخة المحلية فقط عند انقطاع الشبكة.
- لا يوجد أي كود يحذف سجلات Turso تلقائياً عند التهيئة.
- لوحة الإدارة تفتح مباشرة محلياً بدون شاشة تسجيل دخول محلية أو تعليق.
- إعادة كتابة تشغيل P2P المحلي ليتصل بـ Turso مباشرة بدون dynamic import أو Worker محلي.
- طرق الدفع والطلبات وإثباتات الدفع تستخدم Turso الحالي نفسه.
- رسائل الأخطاء الأساسية بالعربية.
- تحديث Service Worker لمنع تشغيل ملفات JavaScript قديمة بعد رفع النسخة الجديدة.

- المتجر: index.html
